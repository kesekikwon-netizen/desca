발굴 단면뷰어 1.0.0
===================

iTwin Capture(ContextCapture) 등이 만든 3MX 실사 메시를 열어, 평면에서 단면선을 긋고
10 cm 레벨선이 있는 깨끗한 단면도를 바로 보고 내보내는 프로그램입니다.

■ 사용 순서
 1. 「열기」(Ctrl+O) → iTwin Capture 결과 폴더의 .3mx 선택 (또는 창에 끌어다 놓기).
    OBJ 도 열립니다(같은 폴더나 상위 폴더의 metadata.xml 에서 좌표계·원점을 읽음).
 2. 「단면선 그리기」(S) → View 1(평면)에서 A, A′ 두 점 클릭.
    끝점·가운데 손잡이를 끌면 View 2(단면)가 바로 바뀝니다. 「방향 반전」(R)으로 보는 방향을 뒤집습니다.
 3. 「두께 띠」 앞/뒤 값으로 입면 영상에 보일 깊이를 정합니다(기본 뒤 0.5 m). 평면에 빨간 괄호선으로 표시됩니다.
 4. 내보내기
    - 단면 DXF: 빨간 단면선(레이어 SECTION_PROFILE, 색 1), 레벨선 10 cm / 50 cm / 1 m,
      표고 라벨(50 cm 마다, 소수 1자리), 입면 영상(IMAGE + PNG). 그리기 순서: 레벨선 → 영상 → 단면선.
      2D 도면(X = A 기준 거리, Y = 절대 표고) 또는 3D 실좌표.
    - 단면 영상: PNG / TIFF / GeoTIFF. 축척(1/10, 1/20, 1/40, 1/50, 1/100 …)과 DPI 로 크기가 정해집니다.
      픽셀 크기 = 0.0254 × 축척분모 ÷ DPI (예: 1/20, 300 dpi → 1.69 mm).
    - 평면 GeoTIFF: 3MX 좌표계(EPSG, 예 5186; 복합 EPSG 이면 수직 기준도 GeoKey 로) + .tfw.
    - 점군 XYZ / LAS: 최고 해상도 꼭짓점, 실좌표(SRSOrigin 적용), 텍스처 색, 범위(전체/두께 띠/현재 화면), 솎기 간격.
    - 단면선 CSV: 윤곽 꼭짓점의 거리·실좌표.
    높이는 3MX 좌표계 값을 그대로 씁니다(변환 없음).

■ 조작
  View 1: 왼쪽 끌기 = 이동, 오른쪽 끌기 = 회전, 휠 = 확대/축소, F = 맞춤, T = 위에서
  View 2: 끌기 = 이동, 휠 = 확대/축소, 두 번 클릭 = 맞춤
  아래 X / Y / Z = 커서 위치의 실좌표, 1·2 단추 = 보기 창 보이기/숨기기

■ 참고
  - 단면은 항상 가장 상세한(잎) 타일에서 자릅니다. 화면용 메시는 가볍게 줄인 것입니다.
  - 그래픽 드라이버가 OpenGL 2.0 을 지원하지 않으면 환경 변수 QT_OPENGL=software 로 실행하세요
    (동봉된 opengl32sw.dll 사용).
  - 설정은 레지스트리 HKCU\Software\ExcavSection\SectionViewer 에 저장됩니다.
  - 외부 구성요소 라이선스: licenses 폴더.
