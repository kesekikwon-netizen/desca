# 디자인 v6 「쓰기 편함」 구현 계획

> 사용자 결정(2026-10-10): v6 「전체 채택」. 스펙: [`docs/design/DESIGN_SPEC_v6.md`](../../design/DESIGN_SPEC_v6.md) (v5 변경분, 어긋나면 v6). 화판: https://claude.ai/artifact/6qRaVBkEjWawkAHeA7hxjk
> **실행 방식:** 작업마다 팩토리 작업(`factory/backlog.md`)으로 돈다 — 명세 → worktree 구현 → 검증 → 검토(검토자 넷) → 사용자 승인 → 병합. 동시 1개. 각 작업은 superpowers 스킬(계획 → 시험 먼저 → 끝나기 전 확인)과 context7(Qt API)을 쓴다. 이 계획은 **문서 단계**이고 코드는 아직 안 바뀐다.

**Goal:** v5 위에 진행 표시 · 막혔을 때 안내 · 도구 막대 · 명령 검색 · 판 접기 · 도면 판 재배치 · 글자 12 px를 얹어, 처음 쓰는 사람도 「지금 어디 · 다음 할 일 · 막히면」을 늘 알게 한다.

**Architecture:** 화면은 `app/`만 바꾸고 계산은 건드리지 않는다(`core/profileGaps` 재사용). 새 부품은 `app/` 안에 `Q_OBJECT` 없이(람다 연결, `static_cast`): `notice.{hpp,cpp}`(Notice 위젯) · `toolrail.{hpp,cpp}`(도구 막대) · `commandpalette.{hpp,cpp}`(Ctrl+K). 같은 `QAction` 을 리본과 막대가 공유한다. 화면 판정은 `--ui-audit`(스펙 §11 항목)에 먼저 RED 로 더한다.

**Tech Stack:** C++17 · Qt 6.10 Widgets · Catch2 v3 · CMake(Ninja · clang-cl) · 빌드 `cmake --build C:/dev/kerf-v4c` · 시험 `C:/dev/kerf-v4c/asec_tests.exe "~CoalescingWorker*"`.
