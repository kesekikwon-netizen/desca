# 3SM 직접 열기 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** .3sm(Bentley ScalableMesh, SQLite) 을 3MX 처럼 열어 평면 표시·단면·내보내기가 되게 한다. 노드 단위 지연 읽기, 변환 캐시 없음.

**Architecture:** 코어 `SmFile` 이 SQLite 를 읽기 전용(immutable) 으로 열어 노드 색인만 메모리에 두고, 노드 하나를 "가상 .3mxb 타일"(`<x.3sm>/n<NodeId>`) 로 `readTmxTile` 에 끼워 넣는다. 그래서 `TileCache`·`LodStreamer`·`collect*`·점군 내보내기는 변경 없이 동작한다. `SmSource : TmxSource` 가 장면(SRS=WKT 원문, origin, 가상 뿌리 경로) 을 채운다.

**Tech Stack:** C++17, SQLite 3.54.0 아말감(정적, `SQLITE_THREADSAFE=2`), zlib(`uncompress`), stb(JPEG), Catch2.

**Spec:** `docs/superpowers/specs/2026-10-11-3sm-reader-design.md` (형식: `research/3sm-format.md`). 기준 커밋 `7ab7d8f`.

## Global Constraints

- 코어(`archsection`) 는 Qt 금지. 새 코어 소스·시험 파일은 `CMakeLists.txt` 목록에 직접 추가(GLOB 아님).
- 원본 .3sm 은 `SQLITE_OPEN_READONLY|SQLITE_OPEN_URI|SQLITE_OPEN_NOMUTEX` + URI `?immutable=1`. 부속 파일(-journal/-wal/-shm) 을 만들지 않는다.
- 연결 하나는 한 번에 한 스레드만(멀티스레드 모드). 풀 최대 8.
- 실좌표 = 로컬 + origin. origin = 뿌리 Extent 중심 xy 를 1 m 반올림, z = 0. **Z 값 불변**. 좌표계 표기는 WKT 원문을 `describeSrs` 로 해석(추측 금지).
- 전체 로드 금지: 열 때 `SMNodeHeader`·`SMMasterHeader` 만. 기하·텍스처는 타일 요청 때.
- 한국어 오류 문구. 커밋은 `feature/3sm-reader` 에만, push·main 병합 금지. D:\desca 작업 트리·`build-local`·`build-msvc`·바로가기는 건드리지 않는다.
- 빌드: `D:\desca-3sm\build-msvc`(스크립트 `scratchpad\build-3sm.bat`), 시험 실행은 PATH 에 `D:\OSGeo4W\bin` 추가 후 `build-msvc\asec_tests.exe`.
