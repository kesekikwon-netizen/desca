# 요청 기록: 조판 탭에도 단면 목록(레이어창) 두기

- 날짜: 2026-10-07
- 상태: 완료
- 관련 문서: docs/intent/2026-10-06-section-viewer-design-board.md, docs/superpowers/plans/2026-10-06-sheet-tab-lock.md

## 요청 원문
> 레이어창이 조판에도있어야하지않나?
> (스크린샷 2장: 작업 화면 왼쪽 「단면 목록 2 · + 새 단면」 판의 A–A′, B–B′ 썸네일 / 조판 탭 「단면도 내보내기」 화면 — 목록 없이 머리에 「B–B′ · 2개 중 2번째」만 보임)

> 2026-10-07: 「순차적진행」(미정 질문 모두 추천대로)

## 문제
조판 탭에는 단면 목록이 없다. 다른 단면(A–A′)의 도면을 만들려면 「작업」 탭으로 돌아가 목록에서 고른 뒤 다시 「도면」을 눌러야 한다. 지금 몇 번째인지는 머리 글자로만 보인다.

## 바라는 결과
조판 탭 왼쪽에 작업 화면과 같은 모양의 단면 목록(썸네일·이름·길이·뒤 깊이)이 있고, 누르면 조판이 그 단면 도면으로 바로 바뀐다. 평면도일 때도 목록이 보이고, 누르면 단면도로 넘어간다(추측).

## 영향받는 곳
조판 탭(평면도·단면도 내보내기 화면), 단면 목록 선택 상태(작업 탭과 같은 선택을 공유).

## 지켜야 할 것
- 조판은 탭이다. 별도 OS 창 금지. 작업 화면 왼쪽·오른쪽 배치는 바꾸지 않는다.
- 단면마다 설정(축척·용지)은 지금처럼 각자 계산. 조판편집 휠 규칙 유지.

## 이번에 하지 않는 것
- 조판에서 단면 추가·삭제·이름 바꾸기(목록 보기·고르기만).
- 여러 단면을 한 장에 같이 넣기.

## 미정 질문
1. 조판의 목록에서 다른 단면을 누를 때 지금 조판에서 바꾼 설정(축척·용지 등)은? — 추천: 용지·넣을 것·형식은 그대로 이어 가고, 축척만 새 단면에 맞춤 — 사용자 답: 추천대로
2. 목록에 「평면도」 줄도 맨 위에 둘까? — 추천: 둔다(평면도 1줄 + 단면들, 누르면 그 도면) — 사용자 답: 추천대로
3. 목록을 숨기는 단추가 필요할까? — 추천: 작업 화면과 같이 리본 「보기 → 단면 목록」 켜고 끄기를 함께 따름 — 사용자 답: 추천대로

## 확인 방법
- 조판 탭 왼쪽에 단면 목록이 보이고, A–A′을 누르면 미리보기·머리가 A–A′로 바뀐다.
- 「작업」 탭으로 돌아가면 목록에서 A–A′이 선택되어 있다.

## 결과
- 조판 탭 왼쪽 「도면 목록」(평면도 1줄 + 단면들). 줄을 누르면 그 도면 조판으로 바뀜. 용지·넣을 것·형식은 이어 가고 축척만 새 단면에 맞춤. 「보기 → 단면 목록」 켜고 끄기를 함께 따름.
- 확인: --sheet-pick 1 → 머리 「A–A′ · 4개 중 1번째」, --sheet-pick 0 → 「평면도 내보내기」, 캡처로 목록·선택 표시 확인. sheet-check RESULT ok(격리 설정), asec_tests 88개 통과.
- 덧붙여 고침: 조판 「저장·취소」 단추가 부모 위젯을 MainWindow 로 잘못 형변환하던 것 → this 로.
- 커밋 안 함(사용자 지시 때만).
