## 문제
Kerf 는 3MX·OBJ 만 연다. iTwin Capture Modeler 가 내보낸 .3sm(광령리 유구배치.3sm 등)은 열 수 없다.

## 바라는 결과
「열기」·끌어다 놓기·최근 파일에서 .3sm 을 고르면 3MX 와 똑같이 평면 보기, 단면선, 조판, 내보내기가 된다.

## 영향받는 곳
열기 대화상자 거르개, 끌어다 놓기, 시작 화면 안내 글, 파일 읽기(loadScene), 배포 폴더(Qt Sql 부품).

## 지켜야 할 것
- 원본 .3sm 은 읽기 전용으로만 연다(바꾸지 않음).
- 좌표 = 파일의 실좌표(EPSG:5186) − 원점, 높이는 파일 값 그대로(지오이드 재적용 없음). 좌표계 문구는 파일 원문(WKT) 그대로.
- 커밋·푸시·배포는 사용자가 말할 때만.

## 이번에 하지 않는 것
- .3sm 으로 저장(쓰기).
- 3SM 의 점군·지형 전용 형식(텍스처 없는 DTM 등) 최적화.

## 정한 것(진행 답 = 승인, 기술 선택은 스스로)
- SQLite 읽기: 이미 설치된 Qt 의 Sql 모듈(QSQLITE) 사용 — 새 내려받기 없음.
- 처음 열 때 한 번 3MX 타일로 바꿔 사용자 캐시 폴더에 두고(진행 막대), 다음부터는 바로 연다. 파일 크기·수정 시각이 바뀌면 다시 만든다.
- 앱 안 표기는 「3SM」, 창 제목·최근 파일·모델별 설정은 .3sm 경로 기준.

## 확인 방법
- 「광령리 유구배치.3sm」을 끌어다 놓으면 평면에 유구 사진 메시가 보인다.
- 단면선을 그으면 단면이 잘리고, 「도면」에서 평면도·단면도 조판이 뜬다.
