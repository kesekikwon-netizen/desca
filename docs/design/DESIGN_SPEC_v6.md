## 2. C8 진행 표시

- 자리: 문서 탭 줄(36 px) 오른쪽 구석. v5의 「Production_2 · 저장됨」 글(`#docTabCorner`)을 대신한다. 오른쪽 끝에 1 px `Edge` 세로선 + 「자동 저장 HH:MM」 12 `Muted`.
- 걸음 셋: 「모델」 → 「단면 n」 → 「도면 k/n」(k = 저장한 장, n = 고른 도면 수 없으면 단면 수). 각 걸음은 둥근 알약(높이 20, 가로 여백 9).
  - 지금 탭의 걸음 = `Card` 바탕 + `Edge` 1 px + 글 `Ink` 700 + 앞에 ● (`ClayText`). 끝난 걸음 = ✓ (`Done`) 평범한 글. 나머지 = 평범한 글(`Muted`).
  - 탭과 걸음의 대응: 홈 = 「모델」(모델이 없으면 「모델 열기」), 단면 = 「단면 n」, 도면 = 「도면 k/n」. 그리는 중은 「단면 n · 새 단면 긋는 중」.
  - 걸음을 누르면 그 탭으로 간다(단면 탭이 꺼져 있으면 눌러도 아무 일 없음, 툴팁에 이유).
- 「자동 저장 시각」은 모델별 설정(단면 목록 · 조판 값)을 마지막으로 쓴 때다. 쓴 적이 없으면 글을 숨긴다.
- 감사: `steps=3 now=<탭 걸음 1> clickable=1`.

## 3. C9 도구 막대

- 자리: 평면 화면 왼쪽 위 (12, 12), 폭 44, 안쪽 여백 4, 버튼 36×36(둥글기 8), `fl` 모양(v5 §5 떠 있는 틀과 같은 바탕 · 테 · 그림자). 평면 화면에서만 보인다(단면 화면의 잘린 돌 칠하기는 안내 칩이 단면 화면에 뜨는 v5 §9 그대로).
- 버튼 위에서 아래로: 선택(기본, 화살표) · 가름선 1×24 · 긋기 `S` · 잘린 돌 `H` · 윤곽 `O`. 아이콘은 리본 칩과 **같은 아이콘 파일**을 쓴다(`section-line` · `hatch` · `outline`, 선택은 Lucide `mouse-pointer-2`).
- 켜진 도구 = `Hand` 채움 + `Ground` 아이콘(리본 도구 켜짐 모양과 같음). 마우스를 올리면 오른쪽에 먹색 말풍선 「단면선 긋기  S」.
- 리본 칩과 막대는 **같은 `QAction`** 이다(켜짐 · 꺼짐 · 눌림이 항상 같이 움직인다). 꺼짐 조건은 `updateEnabled()` 한 곳.
- 안내 칩(v5 §5): 막대가 보이면 칩의 x 를 12 → **64**로, 되돌리기 · 다시는 칩 아래 (64, 56). 칩이 쓸 수 있는 폭이 56 줄어드므로 v5 줄이기 순서(도구 이름 → 숨김 → 문장 줄임표)를 그대로 쓴다.
- 감사: `tool-rail=1 rail-actions-shared=1 rail-guide-offset=64`, 겹침 규칙은 §11 예외.

## 4. C10 명령 검색 (Ctrl+K)

- 리본 오른쪽 끝 칸: 돋보기 + 안내 글 「무엇을 할까요?」(12) + 키 캡 `Ctrl+K`. 폭 142(타일 50 · 좁은 창)는 키 캡을 숨기고 툴팁에만 둔다. 여유가 있으면 176. 칸 높이 32 · 둥글기 8(v5와 같음).
- 누르거나 Ctrl+K: 창 위쪽 가운데에 펼침 상자(폭 440, 둥글기 10, `Card` 바탕 · `Edge` 테 · 그림자 0 8px 28px rgba(20,20,19,.18)). 위에서 입력 줄 40, 결과 줄 36, 바닥 줄 28(「↑↓ 고르기 · Enter 실행 · Esc 닫기」).
- 결과는 세 묶음 — 「명령」(리본 · 메뉴의 모든 `QAction`: 글 · 툴팁 · 키) · 「단면」(이름) · 「키」(F1 목록의 설명). 입력한 글이 들어 있는 것을 보이고 맞는 글자를 700으로. 고른 줄 = `Oat`.
- 지금 못 하는 명령은 회색 + 이유 한 줄(예: 「모델을 먼저 여세요」). Enter 해도 실행하지 않고 이유를 상태줄에 낸다.
- Ctrl+F는 **목록 머리의 거르기 칸**으로 초점을 옮긴다(기존 `filter-persists` 동작 유지).
- 감사: `cmd-palette open=1 query=도면 results>=2 disabled-reason=1`.

## 7. C13 도면 판 (v5 §8의 오른쪽 320 판을 바꿈)

- **종이에서 고르기:** 종이 위 요소 — 표제란 · 범례 · 축척 막대 · 진북(평면도) · 그림 칸 — 를 누르면 고른다. 고른 요소 = 점선 `Ink` 1.5 + 모서리 네 점(8×8, 흰 바탕 · `Ink` 테) + 위쪽 이름표(`Ink` 바탕 · `Ground` 글 12). Esc 또는 빈 곳 = 고름 풀기. (종이 위 그림 자체는 v5 그대로 둥글기 제외 · 인쇄물 규칙.)
- **오른쪽 판 순서:** 머리 「고른 도면 · 단면 1 / 3」 → 이름 명조 20 + 보조 12 → **고른 요소 띠**(`Desk` 바탕 · 둥글기 8: 「고른 요소 표제란」 + 「보이기」 스위치 + 「풀기 Esc」) → **요소별 절**(표제란: 도면명 · 높이 기준 표시 · 작성 / 범례: 항목 보이기 / 축척 막대: 길이 / 진북: 크기 28 mm) → **「종이 · 축척」 절**(항상 펼침: 용지 · 방향 · 축척 1 : 칸 + 맞춤 링크 + 적용 + 격자 4열) → **접힘 줄 셋**(「도면 항목」 범례 · 표제란 · 축척 막대 보임 요약 · 「선 · 글자」 레벨선 pt · 빗금 요약 · 「형식」 SVG · 빈 층 요약; 접힘 줄 높이 40, 오른쪽에 한 줄 요약) → 맨 아래 고정.
- 요소를 고르지 않았으면 요소 띠 · 요소별 절이 없고, 「종이 · 축척」 절부터 보인다.
- **맨 아래 고정:** 조용한 「☆ 이 설정을 기본으로」 + 흙색 「n장 SVG 저장」(40 px) + 「PDF」(고른 도면이 한 장일 때만 켜짐; 아니면 꺼짐 + 「PDF는 한 장만 고르면 켜집니다」).
- **도면 점검 한 줄:** 종이 아래 가운데, 떠 있는 틀 높이 40, 종이 폭: 「도면 점검 · n장」 + 「저장은 막지 않습니다」 + 항목 요약(✓ `Done` / ▲ `Caution` + 고치는 곳 링크) + 오른쪽 펼치기. 펼치면 위쪽으로 자라며 v5 §8 점검 항목 전부(상자 모양)가 나온다. 점검 내용 · 판정은 v5 그대로, **저장을 막지 않는다.**
- 아래 떠 있는 도구 줄(v5 §8): 맞춤 · 확대 · 축소 · **요소 고치기**(켜짐 = `Hand`, 기본 켜짐; 옛 「조판 편집」) · 용지 · 목록.
- v5의 「도면 항목」 타일(72×56)은 없앤다. 항목 보이기 · 숨기기는 고른 요소의 「보이기」 스위치와 「도면 항목」 접힘 줄의 체크 목록으로 한다.
- 감사: `sheet-select title=표제란 panel-section=표제란 check-line=1 save-sticky=1 elem-toggle=1`.

## 8. C14 막혔을 때 안내 한 모양 (`Notice`)

모양: 바탕 · 테 3종, 아이콘 16, 제목 13/700 한 줄, 설명 13 최대 두 줄, 단추 둘(높이 28). **단추는 두 개를 넘기지 않는다.** 주 단추 = `Hand` 채움 + `Ground` 글(고치는 일), 보조 = `Card` + `Edge`(「나중에」 · 다른 길). 흙색 단추는 쓰지 않는다 — 예외는 빈 목록의 「단면선 긋기」(그 화면의 유일한 주 단추).

| 종류 | 바탕 · 테 · 아이콘 | 쓰는 때 |
| --- | --- | --- |
| 알림 | `Desk` · `Edge` · info | 안내만 |
| 주의 | `#FFF4D6` · `#C98A1B` · 글 `Caution` · 삼각 ▲ | 값은 맞지만 확인이 필요 |
| 막힘 | `BlockWash` · `Block` · 글 `Block` · ✕ | 잃거나 못 한 일(저장 실패만) |

| 상황 | 제목 → 설명 | 단추 |
| --- | --- | --- |
| 높이 확인 전 (주의) | 「높이 기준이 확인되지 않았습니다.」→「표고는 파일 값 그대로 보이고, 도면 표제란에는 「확인 전」이 찍힙니다.」 | 「높이 기준 지정…」 · 「나중에」 |
| 빈 구간 (주의, v4 15) | 「s a–b m에서 선이 끊겼습니다.」→「모델에 이 구간이 없을 수 있습니다.」 | 「`E` 다음 빈 구간 보기」 · 「도면에 표시」 |
| 아직 단면이 없음 (v4 16) | 「아직 단면이 없습니다」→「평면에서 두 점을 찍으면 그 선의 단면이 만들어집니다.」 | 「단면선 긋기 `S`」(흙색) · 「연습 모델로」 |
| 저장 일부 실패 (막힘) | 「n장을 저장하지 못했습니다.」→「<파일명> — <이유>. 설정은 그대로 남아 있습니다.」(성공한 것은 ✓ 줄로 위에 남김) | 「실패한 n장 다시 시도」 · 「다른 폴더에…」 |
| 파일 없음 (홈 표 줄) | 「파일을 찾을 수 없음」 | 「다시 찾기」 |
| 명령 못 함 | 회색 + 이유 한 줄 | 없음 |

- 자리: 높이 · 빈 구간은 단면 화면 위쪽(정보 줄 아래), 빈 목록은 목록 가운데, 저장 결과는 판 아래 · 저장 상자. 「나중에」는 이번 실행 동안 숨김(상태줄 배지 · 정보 줄 ▲는 남는다).
- 빈 구간 이동 `E` 키는 이 안내가 있을 때와 정보 줄 「빈 구간 k곳」이 있을 때 동작한다(core `profileGaps` 재사용, 계산 변경 없음).
- 감사: `notice-shape max-buttons<=2 title-lines<=1`, 상황마다 `notice-<상황>=1`.

## 9. C15 작은 추가

- **연습용 합성 모델:** 합성 3MX(`asec-make-synthetic` 결과, EPSG:5186, X 200000–200016 · Y 450000–450012)를 배포 묶음에 넣고, 홈의 「처음이세요? 연습용 합성 모델로 3분 따라 하기」 · 빈 목록의 「연습 모델로」가 연다. 열면 안내 칩이 「① 단면선 긋기 ② 단면 보기 ③ 도면 저장」을 한 걸음씩 안내한다. 크기 · 배포 위치는 **확인하지 못함**(구현 계획에서 확인).
- **길이 숫자 입력 칸:** A를 찍은 뒤 커서 옆에 떠 있는 틀(`fl`) — 「길이 [ 7.43 ] m  `Enter` 로 정하기」. 숫자 키를 치면 바로 칸으로 간다(v5의 「숫자 = 길이」 동작을 눈에 보이게 한 것). 칸 테두리 `Ink` 2 px.
- **이름 바꾸기 `F2`:** C12의 단추와 같은 동작.

## 10. 데이터 규칙 (v5 §10 그대로)

WKT 이름보다 투영 매개변수 우선(5187), 높이 이름표는 값을 바꾸지 않음 — 변경 없음.

## 11. C16 글자와 `--ui-audit` 기대값

- 글자 체계: **12 · 13 · 20**(+ 홈 이름 40). 11 px 허용은 키 캡(`QLabel#kbd`)과 단위 접미(`m` · `pt` · `mm`)뿐. 영향: `ribbonGroupCaption` · `faint` · `monoFaint` · 떠 있는 단추 글자 · 나침반 「진북」 11 → 12. 종이 위 인쇄 요소는 제외(종이 축척을 따른다).
- 위험: 리본 묶음 이름이 12 px 가 되면 칩 폭이 늘 수 있다 — v5 「타일 50은 1916 px 에서」 여유가 4 px 뿐이다. 구현 때 `need50`을 다시 재고, 모자라면 이 항목만 되돌리는 대신 찾기 칸 폭을 줄인다.
- **같은 이름 겹침 예외(C9 · C12):** 감사는 같은 `QAction` 을 노출하는 단추끼리는 겹침으로 세지 않는다. 다른 동작이 같은 이름이면 여전히 실패. `dup 0` 은 이 규칙으로 유지된다.
- v6 감사 항목(v5 항목에 더함): `steps` · `tool-rail` · `cmd-palette` · `panels` · `insp-actions` · `sheet-select` · `check-line` · `notice-shape` · `notice-<상황>` · `font-min=12`. 모두 `RESULT ok`일 때만 끝. B5의 8조합(1280 · 1920 · 3440 · 3840 × 배율 1 · 2)과 `-UiScales 1.25,1.75` 는 그대로 잠금.
